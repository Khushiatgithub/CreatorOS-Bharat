## ✨ Key Features & Architecture

### 1. ⚡ 1-Click Native Indian UPI Gateway
* **Zero Credit Card Dropoffs**: 99.4% payment success rate vs 68% traditional cards.
* **Instant App Intent**: Deep links for **PhonePe**, **Google Pay**, **Paytm**, **CRED**, and **BHIM**.
* **Dynamic Laser QR Scanner**: Real-time animated scanning matrix with copyable VPA.
* **Automated Instant IMPS Payouts**: Direct settlement to Indian bank accounts (HDFC, ICICI, SBI).

### 2. 🧾 Automated GST Invoicing Engine
* **B2B & B2C Tax Compliance**: SAC code classification (`998431` for Digital Goods, `998313` for Mentorship).
* **Automated Tax Split**: Intra-state (CGST 9% + SGST 9%) vs Inter-state (IGST 18%).
* **1-Click GSTR-1 & PDF Export**: CA-ready tax ledgers.

### 3. 💬 WhatsApp Automation Engine
* **Instant Order Fulfillment**: Automated file links and Google Meet invites delivered in under 45 seconds.
* **99.8% Open Rates**: Eliminates email spam folder dropoffs.
* **Abandoned Cart Recovery**: Automatic WhatsApp discount triggers.

### 4. 🧠 Interactive AI Media Kit Studio
* **Live Neural Audit**: Calculates verified engagement rate (`7.8%` vs `2.4%` benchmark).
* **Demographics & Top Metros**: Bengaluru (36%), Delhi NCR (24%), Hyderabad (16%), Mumbai/Pune (14%).
* **Algorithm Golden Windows (IST)**: 07:30 PM - 09:30 PM IST peak window heatmaps.
* **1-Click PDF Export**: Downloadable official rate cards generated via client-side `jsPDF`.

### 5. 🤝 Live Brand Campaign Marketplace Board
* **Top Indian D2C & Tech Sponsors**: **Nykaa**, **boAt**, **Zomato**, **Swiggy**, **Myntra**, **Mamaearth**.
* **Creator Match Scores**: 89% - 98% AI compatibility affinity.
* **NPCI Milestone Escrow**: Guaranteed sponsor payouts.

### 6. 🎨 Visual Bio-Link Storefront Builder
* **5 Curated Indian Themes**: *Linear Royal*, *Obsidian Glow*, *Bharat Saffron*, *Emerald Flow*, *Velvet Purple*.
* **Live Dynamic Mobile Preview**: Real-time updates as you configure products, courses, and calendar slots.

## 🛠️ Tech Stack

* **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Server & Client Components)
* **Language**: [TypeScript](https://www.typescriptlang.org/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom Linear/Stripe Glassmorphism tokens
* **Animations**: [Framer Motion](https://www.framer-motion.com/) (Spring physics, hover lifts, ripple effects)
* **State Management**: [Zustand](https://github.com/pmndrs/zustand) with LocalStorage persistence
* **PDF Engine**: [jsPDF](https://github.com/parallax/jsPDF)
* **Icons**: [Lucide React](https://lucide.dev/)
* **Confetti**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)

## 🚀 Quick Start (Local Development)

```bash
# 1. Clone repository
git clone https://github.com/<your-username>/creatoros-india.git
cd creatoros-india

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
